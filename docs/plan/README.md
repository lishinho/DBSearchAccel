## 项目概览

### 项目名称
DBSearchAccel - 数据库复杂查询加速中间件

### 核心理念
用搜索引擎做高性能条件过滤（查主键ID），用关系型数据库做精准数据详情查询。

### 核心价值
- **性能提升**：复杂查询从秒级降至毫秒级
- **无侵入接入**：业务侧通过配置即可完成基础接入
- **高可用保障**：多级降级、监控告警、数据一致性校验
