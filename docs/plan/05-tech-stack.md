## 二、核心基础组件

### 2.1 后端框架

| 组件 | 选型 | 选型原因 |
|------|------|----------|
| 基础框架 | Spring Boot 2.7.x | 企业级主流框架，生态完善，易集成、易开发 |
| 微服务框架 | Spring Cloud | 服务治理、负载均衡、配置管理一体化 |
| Web框架 | Spring MVC | RESTful API开发标准选择 |

### 2.2 搜索引擎

| 组件 | 选型 | 选型原因 |
|------|------|----------|
| 搜索引擎 | Elasticsearch 7.17.x | 开源主流搜索引擎，支持倒排/正排索引、分词查询，性能优异 |

**关键特性**：
- 倒排索引：高性能条件过滤
- 正排索引：快速字段返回
- 分词索引：模糊查询支持
- 集群模式：高可用、可扩展

### 2.3 缓存中间件

| 组件 | 选型 | 选型原因 |
|------|------|----------|
| 缓存 | Redis 6.x | 开源主流缓存，支持K-V、列表存储，高性能、高可用 |

**使用场景**：
- 实时主键缓存（List结构）
- 分布式锁（SETNX）
- 限流计数（INCR）

### 2.4 数据库适配

| 组件 | 选型 | 选型原因 |
|------|------|----------|
| ORM框架 | MyBatis-Plus 3.5.x | 简化数据库操作，支持多数据源，代码生成 |
| 连接池 | HikariCP | Spring Boot默认连接池，性能优异 |

**支持数据库**：
- MySQL 5.7+/8.0+
- OceanBase 2.x/3.x
- PostgreSQL 12+/14+

## 九、技术选型对比

### 9.1 搜索引擎对比

| 对比项 | Elasticsearch | Solr | 说明 |
|--------|---------------|------|------|
| 社区活跃度 | 高 | 中 | ES社区更活跃 |
| 易用性 | 高 | 中 | ES开箱即用 |
| 实时性 | 高 | 中 | ES近实时 |
| 分布式 | 原生支持 | 需配置 | ES原生分布式 |
| 生态 | 丰富 | 丰富 | 均有丰富生态 |

**结论**：选择Elasticsearch

### 9.2 配置中心对比

| 对比项 | Nacos | Apollo | 说明 |
|--------|-------|--------|------|
| 功能完整度 | 高 | 高 | 均满足需求 |
| 易用性 | 高 | 中 | Nacos更易上手 |
| 社区活跃度 | 高 | 高 | 均为活跃项目 |
| 依赖 | 少 | 多 | Nacos依赖更少 |

**结论**：选择Nacos（Apollo作为备选）

### 9.3 降级熔断对比

| 对比项 | Sentinel | Hystrix | Resilience4j |
|--------|----------|---------|--------------|
| 维护状态 | 活跃 | 停止维护 | 活跃 |
| 功能完整度 | 高 | 高 | 中 |
| 易用性 | 高 | 中 | 中 |
| 控制台 | 有 | 无 | 无 |

**结论**：选择Sentinel
